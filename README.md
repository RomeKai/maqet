**Maqet: from plan to AR to CAD.** Snap a floor plan, redesign the space live with an AI agent, show the client the
result in AR on the table, and hand AutoCAD the exact same design as a measured DXF.

Built for the Meta Global AI Developer Hackathon (Indie track) with the MME harness (on top of ECC).
AI usage is logged in `docs/AI_USAGE.md`.

## What was built during the hackathon

This repository was created after the kickoff (Oct 26, 2026) and contains no pre-existing product code.
All code was written during the event.

The **first commit** also carries material prepared before kickoff, none of it product code:

- **Planning docs:** `docs/PLAN.md`, `docs/PRODUCT.md`, `docs/DECISIONS.md`, `docs/CUTLIST.md`, `docs/RUNBOOK.md`.
- **Dev tooling config:** `AGENTS.md`, `mme/` and `.claude/` (agent instructions, budgets, MME hooks) plus third-party
  ECC rule packs in `.claude/rules/ecc/` (MIT, see their `LICENSE`). MME itself is a separate dev tool, not part of
  this submission.

The demo video opens by stating this split and only shows features built during the event.
